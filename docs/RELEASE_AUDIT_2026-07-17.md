## 按严重度排序的问题

### P0

无。

### P1：选择题存在不可唯一辩护的答案

线上“复利效应”最后一关询问“为了最大化复利终值，哪种干预最有效”，同时提供“延长投资时间”和“同时提高收益率和初始本金”等选项，却把后者判错。题目没有固定变化幅度与其他条件，因此结论无法唯一成立。

修复：

- QualityGate 拒绝“最佳、最有效、最大化”与组合干预同时出现的单选题。
- 初次生成失败后进入现有 LLM repair；修复后仍不合格则使用 Blueprint 确定性兜底或 HonestFailure。
- 生成提示词和 repair 提示词同步加入无歧义单选规则。
- 新增教学契约回归用例。

### P1：知识检查题目可脱离主题

首轮修复部署后，线上 API 为“复利效应”生成的 Flow 已回到 4 分钟，但最后一关变成“入口 A / 入口 B”的通用选择题，与复利、本金、收益率或时间周期无关。旧门禁检查整关文本，标题中的主题词会掩盖题目和选项脱题。

修复：

- QualityGate 对 knowledge_check 的 question 和 options 单独执行 Blueprint 步骤词与主题锚点检查。
- 生成提示词和 repair 提示词明确禁止“入口 A / 入口 B”及无关边界选择。
- 新增知识检查题目脱离主题的教学契约回归用例。

### P1：完成页没有直接进入 Hub 的入口

完成记录能够写入 Hub，但用户在完成页只能继续探索、换起点或重玩，无法自然查看刚刚点亮的路径。

修复：

- 完成页操作栏新增“查看我的图鉴”主按钮。
- 跳转前再次调用完成记录持久化，确保 Hub 可见。

### P2：动态 Flow 显示 7 分钟，偏离 3–5 分钟承诺

四步动态 Flow 的单关时长由模型分别生成并求和，本轮结果显示为 7 分钟。

修复：

- 动态四步 Flow 的每关估时统一为 1 分钟，总计 4 分钟。
- QualityGate 增加 3–5 分钟范围检查。
- 生成与 repair 提示词同步声明四步总计 4 分钟。
- 新增长时 Flow 回归用例。

### P2 观察项：系统路径仍可能出现重复节点

本轮第一关的协作路径中重复出现“复合增长”和“指数函数”。模块卡片本身可区分、互动可以完成，因此当前不阻断发布；后续只在重复节点持续影响理解时修通用路径去重，不为“复利效应”添加专用逻辑。

## 发布验收条件

代码侧必须全部通过：

- npm run build
- npm run eval:teaching

- npm run eval:flow

- 动态 Flow 显示 4 分钟。
- 最终单选题不再出现无条件的“最有效 + 组合干预”结构。
- 完成页可直接进入“我的图鉴”。
- 手机视口下完成页按钮不重叠、不溢出。
- Hub 仍显示本次完成记录。
