## 无限嵌套沙盒 (Infinite Canvas UI)

**来源：** Flipbook 灵感 + Gemini 讨论

**核心概念：** 放弃聊天式上下滚动 UI，整个产品变成一个无限画板。

**交互流程：**
1. 用户输入"期权是什么"→ 屏幕中央渲染 GachaSimulator
2. 组件说明文字中的专业术语（如"行权价""标的物"）自动高亮
3. 用户点击"行权价"→ 旁边的原有组件旁无缝滑出一个新的微型交互组件（如 SliderExplorer）
4. 用户在这个无限大的屏幕上自由拖拽、点击，每点一个盲区就原地生成一个小玩具

**技术方向：** React Flow 或 Framer Motion

**产品价值：**
- 从"打字问 AI"变成"点击即探索"
- 知识探索从线性变成非线性——一个概念连着三个概念，想到哪点到哪
- 和趣灵核心基因吻合——"玩着玩着就懂了"

**当前不做的原因：**
- V1 架构锚定在聊天范式上，画板需要拆地基级别的重构
- Round 1 为聊天体验铺路（Stateful Memory、Schema 三层协议），不对画板所需的空间布局和组件间通信做铺垫
- 缺少用户行为数据支撑决策（聊天 vs 纯画板 vs 双模式）

**可能的演进路径：**
1. Round 1：聊天界面继续做，跑稳 Schema 质量和 Stateful Memory
2. Round 2：T12 sandbox 页面预留空间位置——概念卡片可拖拽、概念间有连线
3. Round 3：sandbox 变主界面，"搜索→组件生成→点击裂变"闭环
