# Epiphany (顿悟) — 产品需求文档 (PRD)

> 版本: v1.0 | 日期: 2026-06-05 | 状态: 待开发

---

## 一、产品定位

**Epiphany** 是一款基于 2026 前沿 Harness 架构的「AI 原生交互式知识学习引擎」。

一句话：**把高价值的长篇枯燥信息，通过 AI 编译成你能秒懂的互动小玩具。**

核心差异：不输出大段文字让你"读"，而是输出互动组件让你"玩"。在玩的过程中，自然顿悟。

---

## 二、目标用户

| 用户画像 | 痛点 | 场景 |
|---|---|---|
| 文科生/非技术背景 | 看不懂专业术语，讨厌长篇文字 | 想了解金融/科技概念但无从下手 |
| 职场焦虑人群 | 没时间深度学习，需要快速建立认知 | 通勤时想高效理解一个复杂概念 |
| 知识爱好者 | 有大量高质量信息源但消化不了 | 听完 3 小时播客，想要提炼核心 |
| Z 世代/二次元 | 传统教育形式太枯燥 | 希望学习像玩游戏一样上瘾 |

## 三、核心用户故事

### Magic Moment（魔法时刻）

> **场景**：文科生小花（平时爱玩《原神》），刷到朋友聊"期权"完全听不懂。

**Step 1 — 输入**
小花打开 Epiphany，输入："期权是什么？用我能听懂的方式讲。"

**Step 2 — 状态识别**
系统瞬间读取小花的历史状态：
- 背景：文科生
- 爱好：《原神》重度玩家
- 知识盲区：金融基础为零
- 偏好隐喻：游戏机制类比

**Step 3 — 多源抓取**
后台 Agent 自动触发播客洞察抓取器，检索到巴菲特在某期访谈中对期权的经典解释原话。

**Step 4 — 编译融合**
AI 将三路信息——「期权概念 + 巴菲特原话 + 原神抽卡机制」——融合推理，输出结构化 UI 指令。

**Step 5 — 魔法呈现**
屏幕上没有长篇文字，而是弹出一个：

```

│   🎴 原神抽卡模拟器 · 期权版      │

│                                 │
│  ┌─────────────────────────┐   │

│  │ 价格：100 原石           │   │
│  │ 权利：若抽出5★角色，     │   │
│  │ 仍按现价1000原石购买     │   │
│  │ [ 买入期权 ]  [ 放弃 ]   │   │
│  └─────────────────────────┘   │
```

**Step 6 — 顿悟**
小花点击"买入期权"→ 十连抽 → 看到金色流星 → 系统提示："恭喜！甘雨当前市价已涨到 2000 原石，但你行使期权，仍以 1000 入手。净赚 900！"
小花 10 秒内理解了「期权 = 锁价权 + 有限损失 + 无限收益」的核心逻辑。不需要读一个字。

## 四、功能需求

### F1 — AI 全局状态记忆 (Stateful Memory)

**需求描述**：系统为每个用户维护一个轻量级状态文件 `User_State.json`，记录跨会话的用户画像。

**状态字段设计**：
```json
{
  "user_id": "u_xxx",
  "profile": {
    "background": "文科生",          // 学术/职业背景
    "hobbies": ["原神", "F1赛车"],    // 兴趣爱好 → 隐喻素材
    "knowledge_blindspots": ["金融", "编程"],  // 已知知识盲区
    "metaphor_preferences": ["游戏机制", "体育竞技"],  // 偏好隐喻体系
    "learning_style": "interactive",  // 学习风格
    "complexity_tolerance": 2         // 复杂度容忍度 1-5
  },
  "conversation_compressed": {        // Harness 压缩的历史摘要，非全量文本
    "recent_topics": ["期权"],
    "key_insights": ["用户对游戏化类比接受度极高"],
    "last_session_summary": "用户理解了期权基础概念，对衍生品兴趣上升"
  },
  "ui_preferences": {
    "theme": "cyberpunk_dark",
    "interaction_density": "medium",  // low/medium/high
    "animation_speed": "fast"
  },
  "updated_at": "2026-06-05T10:00:00Z"
}
```

**关键原则**：
- 不建向量数据库，不存全量历史文本
- 每次会话仅注入压缩后的状态树到 System Prompt
- 状态文件 < 5KB，极轻量

### F2 — 多源高价值信息聚合 (Multi-source Aggregation)

**需求描述**：突破传统图文输入，支持从多种信息源按需抓取高价值内容。

**V1 支持的源类型**：
| 源类型 | 工具名 | 说明 |
|---|---|---|
| YouTube 播客 | `youtube_transcript_fetch` | 抓取视频字幕/转录文本 |
| 网页长文 | `web_content_extract` | 提取文章核心内容 |
| 用户粘贴文本 | `raw_text_input` | 直接粘贴的文段 |

**V2 计划**：
| 源类型 | 说明 |
|---|---|
| Spotify/Apple Podcast | 播客 RSS 抓取 |
| Twitter/X Thread | 大佬长推文提取 |
| arXiv / 论文 | 学术论文摘要 |

**调用逻辑**：
- Agent 判定当前任务是否需要外部信息
- 通过 Function Calling 按需触发
- 抓取结果作为局部变量注入推理上下文，不持久化

### F3 — 个性化隐喻讲解 (Personalized Metaphor)

**需求描述**：AI 不使用通用教学模板，而是根据用户状态动态生成个性化隐喻。

**隐喻生成逻辑链**：
```
用户输入概念
    → 读取 User_State.hobbies + metaphor_preferences
    → 选择最匹配的隐喻域（游戏/体育/音乐/烹饪/...）
    → 结合外部抓取的名人原话
    → 生成定制化隐喻
    → 输出为 UI Schema（非纯文本）
```

**隐喻域映射表**：
| 用户爱好 | 隐喻域 | 示例概念适配 |
|---|---|---|
| 原神/抽卡游戏 | 抽卡/概率机制 | 期权、保险、投资组合 |
| F1/赛车 | 竞速/策略 | 算法复杂度、竞争策略 |
| 音乐/乐器 | 和弦/节奏 | 数学、编程逻辑 |
| 烹饪/美食 | 食材/配方 | 化学、系统架构 |
| 篮球/足球 | 战术/配合 | 管理学、团队协作 |

### F4 — 知识获取零负担互动 (0-Burden Generative UI)

**需求描述**：AI 输出结构化 UI Schema，前端渲染为可交互组件。用户通过交互而非阅读来理解知识。

**V1 核心 UI 组件库**：

| 组件名 | 用途 | 交互方式 |
|---|---|---|
| `gacha_simulator` | 概率/期权类概念 | 点击抽卡，观察收益波动 |
| `slider_explorer` | 因果关系/参数影响 | 拖动滑块，实时看变化 |
| `card_flip` | 概念配对/记忆 | 点击翻牌，正反面对应 |
| `timeline_scrubber` | 历史/进程类 | 时间轴拖拽，事件弹出 |
| `comparison_split` | 对比/辩证类 | 左右分屏，拖拽对比 |
| `quiz_battle` | 知识检验 | 快速问答对战 |
| `build_sandbox` | 构建/系统类 | 模块拖拽组装 |

**UI Schema 协议**（JSON 结构）：
```json
{
  "type": "gacha_simulator",
  "version": "1.0",
  "config": {
    "title": "期权 · 原神抽卡版",
    "quote": "期权就是花小钱锁定未来的选择权",
    "quote_author": "沃伦·巴菲特",
    "pool": [
      { "name": "甘雨(5★)", "probability": 0.016, "value": 1000 },
      { "name": "行秋(4★)", "probability": 0.13, "value": 200 },
      { "name": "班尼特(4★)", "probability": 0.13, "value": 150 }
    ],
    "option_cost": 100,
    "strike_price": 1000,
    "pulls_per_try": 10,
    "explanation_map": {
      "win": "恭喜！角色市价已涨到 {{market_price}}，但你以期权锁定价 {{strike_price}} 买入。这就是期权的杠杆力量。",
      "lose": "没出货。但你只亏了 {{option_cost}}，而不是全款 {{strike_price}}。有限损失，无限收益。"
    }
  }
}
```

## 五、非功能需求

| 需求 | 指标 |
|---|---|
| 首屏加载 | < 2s (LCP) |
| AI 响应延迟 | 首次 Token < 2s，完整 UI Schema 输出 < 8s |
| 状态文件大小 | < 5KB / 用户 |
| 移动端适配 | 响应式，手机端全功能可用 |
| 可访问性 | WCAG 2.1 AA 级 |
| 国际化 | V1 仅中文，架构预留 i18n |

## 六、用户流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  用户输入  │ → │ Harness   │ → │ Agent     │ → │ LLM      │ → │ 前端渲染  │
│  问题      │   │ 读取状态   │   │ 判定是否需要│   │ 编译隐喻  │   │ 交互组件  │
│           │   │           │   │ 外部信息    │   │ 输出Schema│   │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
                                    │                               │
                                    ↓                               ↓
                              ┌──────────┐                  ┌──────────┐
                              │ Tool 调用 │                  │ 用户交互  │
                              │ 抓取播客/  │                  │ 反馈 →   │
                              │ 网页内容   │                  │ 更新状态  │
                              └──────────┘                  └──────────┘
```

## 七、成功指标 (V1)

- [ ] 用户从输入问题到看到交互组件 < 10 秒
- [ ] 单个概念的理解交互完成率 > 70%
- [ ] 用户状态记忆准确率（偏好匹配满意度）> 80%
- [ ] 隐喻相关性（用户自评"讲得通"）> 85%
- [ ] 零传统文字块输出（100% Generatve UI）

---

## 八、范围边界 (V1 不做)

- ❌ 用户注册/登录系统（V1 用匿名 ID + localStorage）
- ❌ 多设备同步
- ❌ 语音输入
- ❌ 社交分享
- ❌ 付费/订阅
- ❌ 管理后台
- ❌ 内容审核（V1 不接入 UGC）
- ❌ 离线模式

---

## 九、风险与假设

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| LLM JSON 输出不稳定 | 前端渲染失败 | Schema 校验层 + 降级为文本输出 |
| 外部源抓取失败 | 缺少高价值语料 | 允许纯 LLM 知识回答作为 fallback |
| 隐喻匹配不准确 | 用户体验差 | 允许用户手动选择隐喻域 |
| 状态机过度压缩失忆 | 上下文断裂 | 保留关键对话摘要的冗余字段 |
