# input-docs 使用说明

这里是**下一轮增量输入**的临时入口，不是当前产品事实的来源。

## 给用户

把新的规划、想法、讨论稿或外部文档放到 `docs/input-docs/` 根目录，然后让我读取即可。

## 给 Codex

处理新输入时必须先做文档整合，再开始开发：

1. 读取根目录新增的 `.md` 文件。
2. 判断它是新增规划、旧内容重复，还是仅适合保留为参考。
3. 将长期产品变化合并进 `../PRODUCT.md`。
4. 将长期技术变化合并进 `../TECHNICAL.md`。
5. 将完成记录或采纳结论写进 `../CHANGELOG.md`。
6. 只在核心文档更新后开始开发。
7. 已整合、重复或失效的输入直接删除；只有仍具独立追溯价值的材料才归档。
