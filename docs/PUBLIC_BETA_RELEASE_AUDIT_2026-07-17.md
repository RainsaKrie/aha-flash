# 趣灵公开测试基础版审计

日期：2026-07-18
状态：源码与本地验收完成，尚未部署

## 结论

公开测试层已经具备默认静态、邀请/开放切换、持久化配额、token 预算、成功缓存、统一模型调用记录、匿名漏斗、完成反馈和受保护指标导出。

五个精选 Flow 直接读取本地内容，不会在页面加载或 API GET 时触发模型。生产环境没有 Upstash 配置时，即使请求开放动态模式也会自动退回静态；每日请求或 token 预算不足时，服务端配置接口也会让所有新页面直接进入静态体验。

代码层面已经具备 20 人静态体验的安全边界，但还不能直接宣布“线上公开测试已就绪”：若要收集反馈与漏斗，仍需先在预览环境配置真实 Upstash；若要开放动态生成，还需完成邀请模式下的真实模型与成本验证。

## 已验证

- `npm run test:public-beta`：14/14 通过。
- `npm run typecheck`：通过。
- `npm run build`：通过，29 个静态页面成功生成。
- 原有指定 Eval：score、flow、flow-dynamic、blueprint、skills、math、teaching 均通过。
- 静态精选 Flow：五个 ID 均可解析，模型调用计数为 0。
- 邀请码：无效、过期、耗尽均在模型调用前拒绝。
- 配额：每日请求与 token 预留使用持久化原子计数；预算不足时全新页面直接显示静态模式。
- 缓存：成功内容重新通过 Schema 与 QualityGate 后才读取，不缓存模型原文。
- Analytics：限制实际 UTF-8 字节数、拒绝未知或敏感字段，Flow 完成按会话去重。
- 反馈：长度、频率和重复提交受控；网络或存储失败不阻断完成。
- 指标：无 Secret 返回 404，正确 Bearer Secret 返回漏斗、反馈与模型成本数据。
- 浏览器桌面端：完成贝叶斯 Flow、提交反馈、点击下一主题并打开 Hub；报表显示开始率、完成率、连续探索率均为 1。
- 浏览器移动端：390 x 844 下 Explore 与 Flow 均无横向溢出，生产会话控制台 0 error / 0 warning。
- 浏览器预算场景：预算不足的新页面直接静态，精选入口保留，指标中 model_calls 为 0。
- 浏览器静态路由：贝叶斯、DNS、期权、工业革命、通胀通缩逐一打开，未出现 `/api/flow` 或 `/api/chat` 请求。

浏览器截图保存在 `output/playwright/public-beta-2026-07-18/`，包括桌面 Explore、完成页、Hub，以及移动 Explore 与 Flow。

## 风险

1. 外部存储未配置时只能静态运行，这是有意的安全降级。
2. 本地文件存储只用于开发，不代表多实例生产能力。
3. 反馈正文属于用户输入，虽限制 240 字且当前 TTL 为 90 天，仍需按实际隐私政策确认保留周期。
4. `open` 模式会扩大成本和滥用面，应该先经过 `invite` 小流量验证。

## 发布边界

本轮没有修改 Vercel 环境、没有部署生产、没有推送 GitHub。上线动作需要单独授权，并应先配置指标存储、以 `static` 发布，再决定是否进入 `invite`。
